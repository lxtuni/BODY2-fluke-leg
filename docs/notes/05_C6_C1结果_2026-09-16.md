## 结论
1. **C6 收拢宽度**：30 → 12 mm 使回收阻力从 −10.7 降到 −3.2 mN（÷3.3），周期平均 +15 %，F̄z 也降 28 %。closed‑only 周期平均 21.0 → 4.8 → 1.9 mN。有效阻力比 a（closed/open 周期平均）0.48 → 0.11 → 0.04。
2. **羽化（5.6 mm）只再多 +1.9 mN（+3 %）**。深挖后修正原因：回收阻力其实与宽度成正比（0.70 mN/mm，截距 ≈ 0，杆/附加质量不是地板），但 12 mm 时回收拖累只剩周期平均的 6 %，羽化最多再拿回其中一半。**羽化机构不做**；把收拢宽做到 ≤ 12 mm 即可。
3. **C1 梯形速度律**：划水冲量 48.6 → 57.2 mN·s（+18 %），周期平均 +32 %（含周期缩短 0.81 → 0.72）。深挖后修正解释：同峰值速率、同 50° 摆角下准定常 ∫v² 本来就只多 18 %，CFD 与之一致；有效 C_N（起动 ≈ 5 → 1.5 弦后 2.5–4）在两种速度律下相同，**并没有被恒速段衰减掉**。理论文档的 +60–70 % 隐含“同一划水时间扫 1.33 倍的角”，即要加大摆角/行程 → C2。代价：|M_y| 峰值 19.3 → 35.6 mN·m（×1.84），F_x 峰 277 → 474 mN，P̄ +52 %，F̄x/P̄ 从 4.13 降到 3.61。**目标是最大推力 → 采用梯形**；若舵机峰值力矩 < 40 mN·m 或电源受限，把斜坡放宽到 60–70 ms 折中。
4. **开合时刻（fold_timing_sweep 一维 + deep_dive_optimal 二维）**：二维最优 τ_o −0.06 / τ_c 0.33（V3trap，+16 % → 87.2 mN；V3c12 τ_c 0.37，+12 % → 63.5 mN）。一维结论：三个新方案最优收扇都在 τ_c ≈ 0.86–0.87 × DUTY（V3c12 0.37、V3trap 0.33），即划水减速开始处，与 04 的目标轨迹一致；提前收扇的收益随回收阻力变小反而变大（V3trap +7.5 mN/0.05 T，早收 → 82.7 mN），晚收代价 −4.9 mN/0.05 T。开扇最优 τ_o ≈ −0.06（回收减速起点），+3–6 %。合成上限：V3trap 早收 + 早开 ≈ 85 mN（现 V3 49.3 的 1.7 倍）。
