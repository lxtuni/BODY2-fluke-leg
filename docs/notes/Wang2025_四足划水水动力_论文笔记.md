# A Computational Study on the Hydrodynamics of Bio-Inspired Quadrupedal Paddling

## 一句话结论

四足划水的总推力不是单腿推力的简单叠加——腿间干涉（Interferenz）几乎总是增益（F̄x / 4F̄SL = 1.00–1.87）；而缩短划水占空比 DR 换来的推力提升，必须用更大的横摇/纵摇/偏航力矩和不成比例增长的能耗去买。

## 研究问题

作者把问题拆成三问：

（I）推进推力如何被划水运动学参数——初始摆角 α₀、摆幅 β₀、划水相占空比 DR——影响？
（II）推力如何被不同的步态序列（trot、对角序 diagonal sequence、同侧序 lateral sequence）影响？
（III）水动力矩（Mx/My/Mz）与能耗如何被上述运动学参数和步态序列调制？

这三问的共同前提是：阻力型推进（drag-based）虽然效率不如身体波动和鳍摆的升力型推进（lift-based），但腿式两栖机器人为了陆上通过性只能接受这个效率损失，所以值得把这个"低效但必要"的机制算清楚。

## 工作缺口

- 此前对四足划水的受力分析基本都停在阻力公式 + 一个假定的 Cd 上，三维腿形和腿间相互作用被整体忽略。作者直言这类简化模型"易用但在实践中可能导致显著误差"。
- 已有的桨腿 CFD 研究（表 1：Zhang 2014 IBM 四腿、Chen 2021 Fluent 滑移网格两腿、Baines 2022 Fluent SIMPLEC 四腿）针对的是小龙虾、海狸式蹼足、海龟，模型与哺乳动物式四足划水形态差别很大。
- **步态序列这一维度此前完全没有被 CFD 研究过**——这是本文自我定位的核心空白。

## 核心贡献

1. 用自研并行三维尖锐界面浸没边界（sharp-interface IBM）求解器，系统扫描 α₀ × β₀ × DR = 3 × 3 × 3 的参数空间，并叠加三种步态，给出完整的单腿与四足对照数据集（表 2、表 3、表 4）。
2. 提出并命名三种阻力型推力生成模式：**Trotting Mode**（双峰，对角腿对交替贡献、且被另一对腿削弱）、**Hindering Mode**（M 形四峰，个体腿的推力被"前一条腿离开划水相进入回程"产生的诱导阻力咬掉一口）、**Separate Mode**（干净四峰，四腿在周期内均匀独立贡献）。
3. 定量给出腿间干涉增益指标 F̄x / 4F̄SL（表 3），证明四足推力普遍大于四倍单腿推力——干涉是增益而非损失。
4. 给出峰值推力时刻的构型规律：在给定 β₀ 下，t_pk 时刻上下肢的相对构型 γ_pk 完全相同，与 α₀ 和 DR 无关；而"前倾更多、上下肢更平"的构型一致对应更低的推力。
5. 给出代价表：trot 的 Mx、Mz 远小于对角序与同侧序；功率与 α₀ 无关、与步态序列（对角 vs 同侧）无关，只由 β₀ 和 DR 决定；DR 由 50% → 33% → 25% 时单周期做功 1.37 → 2.40 → 4.37 J。

## 方法

**几何与运动学.** 模型取自一台真实四足机器人：大腿 L₁ = 10.6 cm、小腿 L₂ = 12.0 cm、肢宽 W = 4.65 cm，前后腿距 L = 32 cm、左右距 D = 12.4 cm。腿被当作**刚性、无变形、无脚蹼**的杆，整机**系留**（tethered，来流 U = 0），采用单向耦合（流体不反过来使结构变形）。角度轨迹 α(t)、γ(t) 由真狗游泳视频重建。

**参数.** α₀ ∈ {60°, 70°, 80°}，β₀ ∈ {20°, 30°, 40°}，DR ∈ {50%, 33%, 25%}。注意周期 T 只由 β₀ 决定（0.8 / 1.2 / 1.6 s），DR 变小意味着**在同一周期内把划水段压得更短、更快**：小腿端平均速度 Ū 从 0.42–0.64 m/s 一路升到 0.84–1.34 m/s。

**数值.** 不可压 N–S，笛卡尔网格 290 × 160 × 160，桨腿附近加密至 Δx = 0.25 cm，Δt = 2 × 10⁻⁴ s，每腿表面 29 940 个三角元。峰值 Re ~ O(10⁴)（trot 3.0 × 10⁴，DR 25% 达 6.2 × 10⁴）**按层流处理，不引入湍流模型**。域分解 256 个子域、256 核并行。取第 5 个周期的结果以摆脱静止初场的影响。附录 A 给出网格（Δx = 0.30 / 0.25 / 0.20 cm）与时间步（3 / 2 / 1 × 10⁻⁴ s）无关性验证。

**无量纲化.** 力除以 ρ U₀²W²，其中 U₀ = 0.42 m/s、W = 4.65 cm——换算下来 **1 个无量纲力单位 = 0.381 N**，这一步对读懂表 2 至关重要。另有推力系数 CT = 2F̄x,avg /(ρ Ū²L₂W) 和功率系数 P̄avg（除以 ρ Ū³L₂W/2）。

## 最强证据

**表 3（F̄x / 4F̄SL）配合图 5a 的 M 形波形。**

表 3 是全文信息密度最高的一张：在 27 个（α₀, β₀, DR）组合里，四足平均推力与"四倍单腿推力"的比值几乎全部大于 1，最高达 1.87（80°, 20°, DR 25%），唯一的例外是 (60°, 20°, 25%) = 1.00。它一次性证明了两件事：腿间干涉在阻力型四足划水里是**净增益**；而这个增益**不是线性可预测的**——同样把 DR 从 33% 压到 25%，(80°,20°) 从 1.52 升到 1.87，(60°,20°) 却从 1.20 掉回 1.00。这就否定了"整机 = 单腿叠加 + 相位移"的简化模型，也正是作者对既有 Cd 假定模型的正面反驳。

图 5a 则是 Hindering Mode 的直接视觉证据：单腿推力波上清晰地被前一条腿进入回程时的诱导阻力"咬"出一个缺口，形成 M 形。这个波形不是统计量，而是机制本身的指纹。

## 对比与消融

- **Baselines：** 单腿（SL）划水。全文每一张四足力曲线上都叠了对应的单腿曲线，这是贯穿始终的基准线，也使 F̄x / 4F̄SL 这个指标得以定义。
- **Ablations：** 三维参数网格 α₀ × β₀ × DR（3×3×3），再乘以三种步态；力、力矩、功率三套输出。
- **被单独验证的模块或因素：**
  - 腿间干涉：通过 F̄x / 4F̄SL 与单腿数据直接相减/相除，单独隔离出来。
  - 步态序列对功率的影响：证明对角序与同侧序功率曲线完全重合 → 序列不影响能耗，只影响力矩相位。
  - 初始摆角对功率的影响：证明 P(t) 与 α₀ 无关（图 11a,b）→ α₀ 是"白拿"的推力参数，减小 α₀ 提高推力不增加能耗。这是全文对工程最直接有用的一条。
  - 数值可信度：附录 A 的网格与时间步无关性。

## 局限与疑问

**我不相信或不确定的地方：**

- **"DR 越小推力越大"其实主要是桨速的收益，不是占空比的收益。** DR 从 50% 压到 25% 的同时，Ū 从 0.42 涨到 1.34 m/s。推力 ∝ v²，涨是必然的。用作者自己按 Ū² 归一的 CT 来看反而是反向的：(β₀ = 20°, α₀ = 60°) 的 CT 随 DR 50 → 33 → 25 单调下降 0.24 → 0.19 → 0.18。也就是说单位"速度平方"换来的推力是在变差的。论文把这一点放进了表 2 却没有讨论。
- **能耗代价被轻描淡写了。** 取同一组 (α₀ = 80°, β₀ = 40°)：四足平均推力 1.90 → 2.89 → 4.49（×2.36），而单周期做功 1.37 → 2.40 → 4.37 J（×3.19）。每焦耳产生的推力掉了约 26%。论文只写了 "additional energy expenditure becomes inevitable"，全文没有任何效率指标（无 Froude 效率、无推力–功率曲线），因此"最优 DR 在哪"这个最有工程价值的问题并没有被回答。（需要注意这个对比里步态也从 trot 换成了对角序，不是纯粹的 DR 消融。）

**可能存在的替代解释：**

- Hindering Mode 的 M 形缺口，作者归因于"前一条腿进入回程产生的诱导阻力"。但同一时刻也正是当前腿自身尾涡脱落与桨面失去附加质量支撑的时刻。论文用的是压力云图的定性观察，没有做"去掉前一条腿"的对照算例，所以两种解释无法区分。
- 四足推力大于四倍单腿，也可能部分来自系留条件下腿群整体在流场中建立的诱导回流（一种"集体加速尾流"效应），而不只是两两之间的干涉。

**实验还不充分的地方：**

- **完全没有实验校核。** 把表 2 的无量纲值换算成有量纲：单腿平均推力 0.29 N（DR 50%）到 0.90 N（DR 25%），四足对角序可达 3.57 N。而 Qu 2025 对真实两栖机器狗的实测是单腿 0.12–0.17 N、整机 0.69–0.92 N，低了 2–5 倍。两者机器不同、尺度不同，不能直接判谁对，但一篇纯 CFD 的论文给出高出实测一个档位的量级而不做任何标定，是需要警惕的。
- 每个参数只取 3 个离散值，作者自己承认这是局限，无法给出 F̄x / 4F̄SL 与运动学参数的关系式。

**作者隐含的假设：**

- 腿是刚性的、单向耦合的（水不使结构变形）；
- Re 达到 6 × 10⁴ 仍按层流处理；
- 无自由面、无机体、无来流；
- **回程与划水的迎流面积完全相同**——这是最关键、也最少被明说的一条假设。

## 与我的研究的关系

### 已经被这篇论文做掉的内容

- **步态序列扫描。** trot / 对角序 / 同侧序对整机推力与力矩的定性影响已经做完，而且对角序与同侧序被证明几乎等价（力曲线相同、功率完全相同，只差 T/4 相位）。我进入整机阶段后不需要重做这一层，可以直接采用其结论：优先稳定性选 trot（Mx、Mz 显著更小），优先推力选对角/同侧序 + 小 DR。
- **"腿间干涉是增益"这个基本判断。** F̄x / 4F̄SL ≥ 1 让我可以放心地先在单腿层面做轨迹优化，把整机耦合当作一个 1.0–1.9 的正向系数，而不是一个先验的惩罚项。这对我目前"先求单腿最优轨迹、再设计结构"的路线是一条直接的授权。
- **α₀ 与构型的规律。** 初始摆角越小推力越大、且不增加功率；峰值推力时刻的上下肢相对构型只由 β₀ 决定。对我的"结构无关目标轨迹"而言，这意味着划水段应尽量贴近水平、避免前倾构型——与我 04 号轨迹（z = −85 mm 的水平直线行程）的取向一致。

### 可以直接借用的方法

- **F̄x / 4F̄SL 指标。** 等我做到四腿，直接用它衡量我的方案的干涉增益，与本文同框可比。
- **无量纲化方案。** 力 / ρU₀²W²、CT = 2F̄x,avg /(ρŪ²A)、P̄avg。我目前一直用有量纲 mN 报结果，补上 CT 一列后就能与本文表 2 以及 Qu 2025 放在同一张图上比较——这是审稿人一定会问的。
- **附录 A 的数值可信度呈现方式。** 三条网格曲线 + 三条时间步曲线叠在同一张 F̄x(t) 图上，简洁有力。我的 overset 算例应当对 V3trap 补同样的两张图。
- **力矩口径。** Mx/My/Mz 绕同一原点在流固界面上积分，并观察到 My,avg 在所有步态下恒为负。这与我 V3trap 的 |M̄y| = 36.7 mN·m 是同一套讨论口径。

### 它留下的研究空白

这四条正好是我在做的事，可以逐条对应写进我的引言：

1. **回程自由度完全缺失。** 本文的腿在回程和划水时迎流面积完全相同，所以回程阻力不可避免且随回程速度平方增长——全文所有"回程是负贡献"的结论都建立在这个假设上。我的第一套（120° 折扇收拢到 12 mm，面积比 27%）和第二套（刚性板绕桨杆羽化 90°，面积比 13%）要消掉的正是这一项。我的 C6 系列已经量到：只把回程面积收小，净推力 49.3 → 56.7 mN（+15%），回程段相平均力从 −19.3 mN 改善到 −5.9 mN。本文没有、也不可能有这个维度。
2. **速度律（Geschwindigkeitsgesetz）不是设计变量。** 本文的 α(t) 是从狗的视频重建的一条固定曲线，DR 只把它整体缩放。我把速度律本身当成可设计的对象：在同样峰值角速度和 50° 摆幅下，梯形律相比余弦律的 ∫v²dt 高 18%；CFD 实测 V3c12 56.7 → V3trap 75.0 mN（+32%）。（诚实地说，这 +32% 里不只是速度律——V3trap 同时把 T 从 0.81 缩到 0.72 s、DUTY 从 0.45 降到 0.382，所以它和本文的 DR 扫描犯的是同一类混淆，只是方向相反。这一点我在自己的报告里需要拆干净。）
3. **开合/羽化时机没有对应自由度。** 我的两态合成扫描给出最优切换点 τ_o = −0.06、τ_c = 0.33（= 划水段的 82–86%），并且两个切换点都对应同一个临界桨速 ≈ 0.20–0.26 m/s ≈ 0.7 v_max。本文没有可切换的状态，自然没有这个维度。
4. **最优 DR 的判据缺席。** 本文只得到"DR 越小推力越大"的单调趋势，止步于此。我这边有一个可解释的判据：最优占空比由回程与划水的有效阻力比 a_eff = (F_rec/F_pw)(v_p/v_r)² 决定，我的三种构型分别是 a_eff = 0.10（回程全开）/ 0.03（收拢 12 mm）/ 0.013（羽化板）。a_eff 越小，理论最优 DUTY 越大；但真实系统里回程速度受舵机限速，DUTY 最终落在由路径长度比给出的 0.4–0.5。本文的 a_eff 固定且偏大，所以它看到的只是这条曲线上的一段。

### 对机构、控制、算法或实验的启发

- **作动器量级的对照。** 本文明确点名 GXservo-X50（50 kg·cm）防水舵机。我选的 7465W 只有 5.8 kg·cm @ 8.4 V——但我的桨板小一个量级（18.5 cm² vs 他们的 55.8 cm²）、桨速小 2–4 倍，估算脚踝峰值力矩 0.4 kg·cm、髋 0.6 kg·cm，余量仍然很大。反过来这提醒我：一旦把桨面放大到他们那个尺度，力矩会从"任何舵机都够"变成真正的瓶颈；D2w73（板加宽到 73 mm）就是往那个方向走的一步。
- **D2w73 的判据要改。** 本文的规律是"推力↑必然伴随力矩↑、能耗↑"。我预期 D2w73 推力 ×1.5，那么按此规律 |M̄y| 和 F̄z/F̄x 会同步变差。所以 D2w73 的取舍判据应该以 F̄z/F̄x 和 |M̄y| 为准，而不是只看净推力——这一条我要写进算例判据表。
- **浮心高于重心。** 作者建议 CB 置于 CG 之上以抑制横摇。我的 M3 船体设计应当据此核对浮心/重心的相对高度。
- **可引用的空白陈述。** 作者写道，基于学习的方法已用于腿式机器人的步态学习与能效优化，"但学习过程中腿式机器人与流体介质的相互作用仍未被探索"。这正是我在考虑的 RL / 最优控制方向所需要的空白陈述，可以直接引用。

## 关联知识

- 阻力型推进（drag-based）与升力型推进（lift-based）的分野，及其与陆上通过性之间的取舍——这是所有腿式两栖机器人的底层折中。
- 尖锐界面浸没边界法（sharp-interface IBM）+ 笛卡尔网格 + 域分解 MPI 并行，作为 overset（重叠网格）之外的另一条处理大位移运动边界的路线；节点分为 fluid / solid / ghost / hybrid 四类的处理方式。
- 三个可复用的无量纲指标：推力系数 CT、功率系数 P̄avg、腿间干涉比 F̄x / 4F̄SL。
- 三种推力生成模式（Trotting / Hindering / Separate）——作为描述"多桨相位关系"的一套现成语言，比"两相/四相"更有物理含义。
- "峰值推力构型只由摆幅决定"这一类构型不变量，可作为检查自己轨迹是否落在合理区间的快速判据。
