## 一分钟版

一篇纯 CFD 的参数扫描：一条四足划水机器狗模型，扫 **初始摆角 α₀ × 摆幅 β₀ × 划水相占比 DR × 三种步态序列**，共 27 个单腿算例 + 整机算例。三个结论对你有用：

1. **行程中心角越低，推力越大** —— α₀ 从 60° 升到 80°，单腿平均推力掉 43 %。你的 V3 把中心角从 106° 压到 95° 拿到更多推力，方向被独立验证了。
2. **压缩划水相 → 推力 ×2.4，但推力系数（≈ 效率）×0.55** —— 和你 V1 vs V2 的取舍（效率 2.84 vs 3.45 mN/mW）是同一件事。
3. **腿间干涉是正的**：整机推力always > 4 × 单腿推力，比值 1.02–1.87。**你用单腿 ×4 估整机是偏保守的**。但四相序列增益更大（1.17–1.71）的同时，三个轴的水动力矩都远大于两相小跑。

一个直接可用的推论（我从他们的机理 + 你的 DUTY 推的）：**V3 的 DUTY = 0.45 恰好适配两相步态**——两对腿错开 T/2，划水窗口 0.45 + 0.45 = 0.90，几乎不重叠、只留 2×0.05T 的空档；换成四相 T/4 偏移则相邻腿必然重叠 0.20T，正好落进他们说的 Hindering 模式。见图 D。

## 他们到底做了什么（第 2 节）

**几何**：上肢 10.6 cm、下肢 12.0 cm、肢宽 4.65 cm；前后腿间距 L = 32 cm、左右间距 D = 12.4 cm。比你的腿大 ~2.5 倍（你 50 mm 杆 + 42 mm 桨头 = 92 mm）。

**运动学**：⚠️ **没有解析式**。上肢角 α(t) 与下肢相对角 γ(t) 是从一段游泳狗的视频逐帧重建出来的曲线（Figure 1c），三个参数只是对这条曲线做平移/缩放/时间压缩：
- α₀ ∈ {60°, 70°, 80°}：整条曲线的偏置。Table 2 里峰值推力时刻的角度恒为 **α_pk = α₀ + 10°**。
- β₀ ∈ {20°, 30°, 40°}：角度范围的缩放。**γ_pk = 75° − β₀**。
- DR ∈ {50 %, 33 %, 25 %}：划水相占周期的比例。

⚠️ **论文里有一处自相矛盾**，引用时要小心：正文说"因为步进电机转速恒定、划水相时长固定，DR = 50/33/25 % 对应周期 T = 0.8/1.2/1.6 s"，但 Table 2 的 T 列明明是跟着 **β₀** 走的（β₀ = 20/30/40° → T = 0.8/1.2/1.6 s，与 DR 无关）。Table 2 的读法才自洽：同一 β₀ 下 DR 越小，桨尖均速 Ū 越大（β₀=20° 时 0.64 → 0.96 → 1.34 m/s），这只有在 **T 不变、划水相被压缩** 时才成立。所以**他们的"DR 降低"= 周期不变、划水划得更快**，不是狗式的"划水快 + 回收慢"。
→ 对你意味着：**他们的 DR 结论和你的 V1/V2 实验不是同一个变量**。你的 V1 vs V2 是划水速率相同、只改回收时长；他们是周期相同、只改划水速率。两者都指向"别把时间花在慢划水上"，但机理不同，报告里要分清。

**流动条件**：
- Re ≈ **3.0 × 10⁴**（按肢宽 W = 4.65 cm 与划水相桨尖均速 Ū = 0.64 m/s）。**你的桨头 Re ≈ 1.1 × 10⁴，同一量级** —— 这点很重要，说明他们的结论在你的雷诺数区间可以借用。
- ρ = 1 g/cm³，μ = 0.001 Pa·s；Re = O(10⁴) 所以**不加湍流模型**（和你单腿算例用 laminar 的理由一样，可以互相引用）。
- **机体固定（tethered，无位移）、刚性腿、无自由面**。计算域是 20L × 32D × 12L 的闭合长方体，六个外面都是零速度 + 零法向压力梯度 → 完全淹没、没有空气–水界面。
- 网格 290 × 160 × 160 非均匀笛卡尔，桨周围 Δx = Δy = Δz = 0.25 cm；Δt = 2×10⁻⁴ s。无关性验证扫了 0.30/0.25/0.20 cm 与 3/2/1×10⁻⁴ s（附录 A）。求解器是自研的 **sharp-interface 浸没边界法**。

**力的定义**：
- 推力无量纲化用 **ρ_f U₀² W²**，其中 U₀ = 0.42 m/s（β₀=40°、DR=50 % 的桨尖速度）对所有算例统一使用，所以不同算例的 F̄x 曲线可以直接叠着看。
- 推力系数 **C_T = 2 F_x,avg / (ρ_f Ū² L² W)**，这里的 Ū 是**各算例自己的**桨尖均速 —— 所以 C_T 才是效率类的量（除掉了速度）。
- 力矩 M_x/M_y/M_z（横摇/纵摇/首摇）对流固界面积分，原点取四条腿上肢铰链的中点。**论文没给力矩的无量纲化因子，也没有力矩数值表，只有图 9/10 的曲线**。
- 功率 P(t) = −∫ F·u dΓ；平均功率系数用 ρ_f Ū³ L² W / 2 归一。

## 结果（第 3 节）——哪几段该细看

### ① Table 2（单腿，27 行）：三个参数的趋势
**这是全文最该抄进你报告的一张表。**

- **α₀ ↑ → 推力 ↓，单调。** β₀=20°、DR=50 % 时：F̄x,avg = 0.75 → 0.59 → 0.43（α₀ = 60/70/80°），**降 43 %**；峰值推力 F̄x,pk = 10.53 → 9.90 → 8.79。机理他们说得很清楚：**"前倾、上下肢更展平的位姿在峰值推力时刻始终产生更低的推力"**。
  → 这正是你 V3 的机理（把行程中心压低，出力最大那段桨更接近竖直）。但**注意角度定义**：他们的 α 是上肢相对机体的位置角，你的 ψ 是摇臂相对 +x 的方向角，两者基准不同。引用时别直接对数字，只对**方向**：低中心角 = 更多推力。用之前先看 Figure 1b 确认他们的角度零点。
- **β₀ ↑ → F̄x,avg ↓，但 C_T ↑。** 因为 T ∝ β₀（0.04 s/度），摆幅加大的同时周期也加长、桨尖变慢。所以"大摆幅推力小"在他们这里是**周期变长的副作用**，不是摆幅本身不好 —— 这点论文没有拆开，是个可以批评的地方，你在报告里可以指出（你自己的 V3 把 SWEEP 从 60° 降到 50° 同时缩短周期，是把两者解耦了）。
- **DR ↓ → 推力大涨。** F̄x,avg 0.75 → 1.27 → 2.35（β₀=20°, α₀=60°）。但 C_T 同时 0.24 → 0.19 → 0.18。**推力 ×2.4、效率 ×0.55**（9 组均值，见图 B）。
- **峰值时刻随 DR 后移**：t_pk ≈ 0.58–0.63 T（DR=50 %）→ 0.71–0.74 T（33 %）→ 0.80–0.81 T（25 %）。

### ② 三种推力模式（Figure 7–8）——**你整机步态决策的核心**
- **Trotting Mode**（两相小跑，DR = 50 %）："每一对对角腿在周期内交替、等量地贡献推力，而它的贡献被另一对对角腿削弱。" 一个周期两个推力峰，间隔 T/2。
- **Hindering Mode**（四相序列，DR = 33 %）："单条腿的推力被前一条腿离开划水相、进入回收相时产生的阻力显著削弱。"
- **Separate Mode**（四相序列，DR = 25 %）："四条腿各自独立贡献推力，形成周期内均匀分布的紧凑四峰波形。"

**关键的数量关系**（论文没明说，我替你算了）：四条腿按 T/4 错开时，只有 **DUTY ≤ 0.25** 才进得了 Separate 模式；DUTY 越超过 0.25，相邻腿重叠越多、Hindering 越重。
→ 你的 V3 是 **DUTY = 0.45**，四相时相邻腿重叠 0.20 T，**必然是 Hindering**。而两相（对角对错开 T/2）时 0.45 + 0.45 = 0.90，**几乎不重叠**，只在 τ ∈ [0.45,0.5) 和 [0.95,1) 各有 0.05 T 的空档。图 D 画的就是这个。
→ **推论：V3 该配两相步态。** 若想用四相吃到更大的干涉增益，就得把 DUTY 降到 0.25 附近 —— 但那是另一个步态，要重跑 CFD。

### ④ 力矩与能耗（Figure 9–10 + 第 4 节）
- **只有定性结论，没有数值表**："对角与侧序列步态的 M_x、M_y、M_z 彼此非常接近……相比之下小跑步态的三个力矩都小得多，尤其是 M_x（横摇）和 M_z（首摇）。" DR 越小力矩越大（Separate 模式最大）。
- **能耗**：α₀=80°、β₀=40° 固定，DR 从 50 % → 33 % → 25 %，单周期做功 **1.37 J → 2.40 J → 4.37 J**（涨 3.2 倍）。注意 Table 4 里归一化的功率系数反而是降的（3.50 → 2.41 → 1.62），因为归一化因子含 Ū³。**引用时务必用有量纲的 1.37/2.40/4.37 J，别用归一化值，否则会得出相反的结论。**
- 作者提醒：用低 DR 的四相序列时，**必须配基于实时振动信号的反馈控制**，否则机体姿态会抖。

### ⑤ 步态定义（Figure 1d）
- 两相小跑：对角对（LF+RH / RF+LH）同相，两对错开 **T/2**。
- 四相对角序列：**LF → LH → RF → RH**，依次错开 **T/4**。
- 四相侧序列：**LF → RH → RF → LH**，同样 T/4。**推力几乎与对角序列相同**（所以四相选哪种只看力矩和控制方便）。
- 附带一个细节：垂向力比推力**超前约 6.25 % 周期**（T/16）。你做垂向力分析时可以对照。
